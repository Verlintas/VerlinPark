# ADR-0010: v0.1 范围

- 状态：Accepted
- 日期：2026-10-21

## 背景

ADE 很容易范围蔓延：IDE、模型市场、文档、插件、云同步。需要在第一个版本证明核心价值。

## 决策

v0.1 只做“三层 Agent 组织完成一个跨模块 feature”的完整闭环：

- macOS 原生 App + Rust daemon
- 三层组织 + Plan 校验 + DAG 调度
- typed message + artifact
- 每任务 worktree + 集成分支 + merge queue
- 手动模型/预算
- OpenAI-compatible + Anthropic
- 终端、diff、Park Map、Trace、成本、审批
- CLI（run/status/attach/diff/logs）
- 签名/notarize DMG

**不做：** MCP、ACP、Skills/Hooks、插件 SDK、内置 MLX、PR 自动创建、多窗口、远程 daemon、逐 hunk accept/reject。

## 理由

- 核心差异化是“多 Agent 组织 + 可观测 + 可合并”，不是功能数量。
- 先打穿一条真实工作流，再扩展。
- 降低单人维护风险。

## 后果

- v0.1 不是“全能 ADE”，需要清晰沟通。
- 外部 Agent/本地模型用户要等 v0.2/v0.3。
- 任何新功能必须进 v0.2+ 或替换现有范围。
