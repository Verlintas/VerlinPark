# ADR-0006: 事件溯源 + SQLite 投影

- 状态：Accepted
- 日期：2026-10-21

## 背景

ADE 需要审计、回放、崩溃恢复、多客户端同步。只存当前状态会丢失过程；只存日志查询困难。

## 决策

- 每个 Session 的 append-only JSONL 事件日志是 source of truth。
- SQLite 作为投影/索引，用于 UI 查询。
- 事件带单调 `seq`；客户端可从 `since_seq` 恢复。
- 启动时可用事件重建 SQLite。
- 大输出/产物写 artifact，不写事件正文。

## 理由

- 可回放、可审计、可恢复。
- SQLite 查询快；事件日志便于导出/调试。
- 为未来远程/多客户端打基础。

## 后果

- 需要事件 schema/版本、投影重建、写入顺序/fsync 策略。
- 事件日志会增长；需要保留/清理策略。
- 不能随意改事件语义；只能加字段/新事件。
