# ADR-0003: 手动模型与预算配置

- 状态：Accepted
- 日期：2026-10-21

## 背景

多 Agent 的成本可能很高。自动模型路由可以省钱，但会引入不透明性和不可预测性；硬核用户通常希望自己决定每个角色的模型和预算。

## 决策

- **不自动路由、不自动降级、不偷偷换模型。**
- 用户在 Session 创建时为每个角色选择模型。
- 预算可设在 Session / Department / Task 三级。
- Runtime 只做能力校验、80% 告警、100% 硬停。
- 提供显式模板/预设，但必须用户手动应用。

## 理由

- 用户明确选择“全手动配置”。
- 可预测的成本和质量。
- 便于审计“为什么用这个模型”。
- 避免自动路由在 coding 任务上做出错误取舍。

## 后果

- 配置负担较高；需要好的 onboarding、模板、批量填充、成本预估。
- 用户可能选到不支持 tool calling 的模型；启动前必须阻止并提示。
- 效率优化靠调度/上下文/缓存，而不是偷偷换模型。
