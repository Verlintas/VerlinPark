## Notes

- Wikimedia Commons file pages contain the full attribution and license terms. The table above is a summary.
- `Public domain` and `CC0` files are used without additional restrictions.
- `Sapphic` and `Two-Spirit` are CC BY-SA 4.0; attribution is provided above and the license is linked. Those assets remain under CC BY-SA 4.0.
- `Gay Pride Flag.svg` is listed by Wikimedia Commons as “Copyrighted free use”; see its file page for the exact permission.
- PNG assets were downloaded as Wikimedia 1024/1280px thumbnails and renamed for the app. No artwork was redrawn.
